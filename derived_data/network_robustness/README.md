# Network robustness derived summaries

This directory contains public, small derived summaries from the network robustness analyses used in the revised manuscript.

The analyses were generated by `ctos-repro network-robustness` from the external ECv matrix `TH090_ECv_matrix_full.txt`, which is not redistributed in this repository because it is an intermediate matrix derived from controlled-access transcriptomic data.

Included summaries cover:

- ΔECv threshold sensitivity at 0.25, 0.30, and 0.35;
- full-cohort common-network support across all ten organoid lines;
- exact moderate-versus-resistant label permutation tests;
- exact same-size subset permutation;
- legacy versus canonical cetuximab common-network comparison;
- truth-lock reproduction summaries for the previous LDN-193189 and cetuximab common-edge sets.

These files are intended to support manuscript reproducibility and Supplementary Table S4. They are not raw sequencing data and are not a replacement for controlled-access WES/RNA-seq data deposited at EGA.
